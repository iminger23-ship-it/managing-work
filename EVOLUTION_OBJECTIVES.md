# Measured Self-Evolution Objectives

MyLocalAI uses explicit measurable objectives. The local model does not define success by its own prose.

## Intelligence — 30%
- answer feedback accuracy
- research grounding
- coding-task success

## Knowledge — 20%
- live research success rate
- source retrieval/fetch success

## Tool use — 20%
- command success rate
- launch failures
- workflow completion

## Efficiency — 15%
- response latency
- process CPU/GPU/RAM telemetry
- context-footprint efficiency proxy

## Reliability — 10%
- successful interaction rate
- evolution regressions

## Personalization — 5%
- useful learned skills
- repeated-task reduction
- habit prediction success

## Autonomous acceptance
A candidate must pass actual source validation, must not regress the capability benchmark, and must have a positive objective-score delta. A neutral candidate may be reviewed manually but is not silently applied.

## Deep code editing
Autonomous edits are allowed across application source including the root engine, GUI, Core, services, models, and tools. The evolution controller, mission policy, safety boundary, and evaluator tests remain protected so the system cannot quietly disable the mechanism that judges its own improvements.
